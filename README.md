# Sully's Mii-Bongo — téléchargements

Un Mii en 3D qui tape au clavier, joue des bongos, tient une manette ou un volant et parle avec votre micro, dans une fenêtre sur le bureau et comme source OBS (Windows 10 / 11).

**[⬇ Télécharger la dernière version](https://github.com/Le1Sully/sullys-mii-bongo-releases/releases/latest)** : prenez le fichier `Sullys-Mii-Bongo-vX.Y.Z-win-x64.zip`, décompressez-le et lancez `Sully's Mii-Bongo.exe`.

Il faut le [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) et WebView2 (déjà présent sur Windows 11). Le mode d'emploi complet est dans `Lisez-moi.md`, dans le zip.

Depuis la version 1.1.0, l'appli se met à jour d'elle-même : Réglages → OBS & système → 🔄 Mises à jour → *Rechercher une mise à jour*.

Ce dépôt ne contient que les versions publiées.
